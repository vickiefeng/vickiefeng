### Featured Project

**Housing Saleability Analysis** \
A collaborative data science project analyzing approximately 18,000 California single-family home listings using real-estate listings and 2021 sales data to investigate factors associated with whether properties sold. The project included data cleaning and integration, exploratory analysis, statistical hypothesis testing, text analysis, geographic analysis, and development of an interpretable composite saleability score.
